# QLab：A 股多因子选股与趋势择时

周三上午班 L 组（4 人）课程作业。

本组的选题是搭建一套能够在本地复现的 A 股量化研究与交易系统。选择这一选题，一方面是因为课程
要求系统必须有真实的策略与回测内核，另一方面也是希望把课堂上的因子研究、横截面选股与趋势择时
放进同一套代码里检验：策略是否成立，最终要由历史数据说话，而不能停留在公式和示意图上。

系统以 A 股日频行情为对象，覆盖数据接入、因子计算、样本内因子筛选、组合构建、择时、T+1 撮合、
绩效统计与结果展示。回测引擎、撮合与费用模型均为本组自行实现，没有调用 backtrader、vnpy 一类
第三方回测框架；数据源、参数与成本假设全部显式记录，按 README 的步骤可以在另一台机器上重跑。
代码按数据层、计算层、策略层、回测层与展示层分开，各层之间只通过行情面板（`MarketPanel`）与
回测结果（`BacktestResult`）传递数据，便于单独测试，也方便在答辩时说明每一处取舍。

如果只想确认流程能跑通，直接双击 `回测.bat`；想手动一步步来，用下面几条命令。

## 环境与运行

Python 3.10 及以上，开发与测试环境为 3.12。

```bash
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
pip install pytest                    # 可选，习惯 pytest 时使用；unittest 无需安装

python scripts/download_data.py --size 300 --rounds 3
python scripts/run_backtest.py
python -m qlab web                    # 默认 http://127.0.0.1:8000
python -m qlab report                 # 生成 Word 技术报告
```

`download_data.py` 需要联网，300 只标的约需十几分钟。若只是想验证流程，可以先抓 30 只：

```bash
python scripts/download_data.py --size 30 --rounds 1
python scripts/run_backtest.py --top-n 10 --no-ablation
```

## 策略设计

候选因子共 12 个，定义在 `qlab/config.py` 的 `FACTOR_POOL` 中，覆盖动量、反转、波动率、
流动性、趋势与高阶矩六类。每个因子附有方向标记，+1 表示数值越大预期收益越高，-1 表示相反。

因子的取舍只使用 2023 年之前的数据（2017-06 至 2022-12，含因子滚动窗口的预热段）的月末样本。
先计算因子与未来 21 个交易日收益的横截面秩相关（Rank IC），再汇总为 ICIR。按 |ICIR| 从大到小
依次纳入，若与已选因子的截面相关性达到 0.75 则跳过，同时要求 |ICIR| 不低于 0.15，最多保留 5 个。

实际只有 3 个因子通过筛选：turn_20、skew_60、bias_60，方向均为反向。三者的样本内 t 值分别是
-1.66、-1.62 和 -1.54，未达到通常的显著性水平，技术报告中对此作了说明。

合成得分时，方向取样本内 IC 的符号，权重按 |ICIR| 归一化。每个调仓日先做 2% 的双侧缩尾，
再做横截面 z-score，然后加权求和；若某只股票当期缺少某个因子，则按剩余有效因子的权重重新归一。
组合取综合得分前 30 只等权持有（等权约 3.3%，低于 8% 的单票上限，该上限本样本未触发），
月末最后一个交易日出信号，次一交易日开盘调仓；当日停牌（无开盘价）的标的不参与调仓。

择时环节只调整总仓位，不改变选股名单：沪深 300 收盘价位于 120 日均线上方时满仓，
下方时将仓位系数降至 50%。50% 是按“最大回撤不超过 15%”的预算选定的：30%/40%/50% 的全样本
回撤分别为 -15.9%/-15.2%/-14.5%，50% 是预算内仓位最高、收益与夏普也最高的一档；技术报告
7.1 节给出了样本内/外的分段敏感性。

交易成本按 A 股规则设定：佣金万分之二点五、单笔最低 5 元；印花税在卖出时收取，
2023-08-28 之前为千分之一，之后为万分之五；单边滑点 5bp；买入按 100 股整手向下取整。

## 回测设置与结果

回测区间为 2019-01-02 至数据末端，样本内截至 2022-12-31，样本外自 2023-01-01 起，两段分别统计。
基准选用沪深 300 价格指数，与个股采用的不复权价格口径一致。

课程要求的四项指标均已给出，包括累计收益率、年化收益率、最大回撤与夏普比率；此外还计算了
索提诺比率、卡玛比率、信息比率、年化超额、Beta、Alpha、胜率与换手率。年化统一按 252 个交易日处理。

| 指标 | 策略 | 沪深300 |
| --- | ---: | ---: |
| 累计收益率 | 65.3% | 31.3% |
| 年化收益率 | 6.8% | 3.7% |
| 最大回撤 | -14.5% | -45.6% |
| 夏普比率 | 0.45 | 0.21 |

全样本累计 65.3%、年化 6.8%，同期沪深300 为 31.3%、3.7%；年化超额（几何口径）3.2%，
信息比率 0.17、Alpha 4.2%。最大回撤 -14.5%，约为基准 -45.6% 的三分之一；夏普 0.45，
是基准 0.21 的两倍。分区间看，样本内年化 9.1%（基准 7.1%）、样本外 4.4%（基准 0.1%），
两段都跑赢基准。

成本与换手：年化双边换手约 10.2 倍，按成交表实测交易成本（佣金+印花税+滑点）约 1.18%/年，
成本前毛超额约 4.4%/年。另取中证 500 作风格参照：同期年化 4.8%、最大回撤 -41.8%，
策略收益高于中证 500，回撤只有其三分之一。

仓位层的取舍：关闭择时后年化 14.8%、最大回撤 -23.8%、夏普 0.78；50% 仓位为 6.8%/-14.5%/0.45。
可见择时在本样本上不是收益增强项，而是把回撤压到 15% 以内的约束；技术报告第七节与 7.1 节
列出了全部敏感性结果。

净值曲线按 1.0 起算，图上标出了建仓与加减仓的位置，并画出了样本内外的分界线。

## 网页看板

```bash
python -m qlab web          # 默认 http://127.0.0.1:8000
```

首次打开时进程里还没有结果，页面会用默认参数真跑一遍回测（本地行情已缓存时约数秒）；之后再打开
会直接加载最近一次结果。看板内容与报告口径一致：结论摘要与 8 张指标卡（可切换全样本/样本内/样本外）、
归一化净值（策略/基准、建仓与加减仓标记、样本内外分界、底部减仓色带）、策略与基准回撤、仓位与择时、
年度收益对比、相对强弱、三段指标对比表、超额收益与成本、策略/基准月度热力图、因子检验、
最新目标组合、最近成交、系统模块与数据设置。切换区间时，净值会按区间首日重新归一，回撤也在区间内重算；
图表全部由原生 Canvas 在浏览器端绘制，不依赖 CDN，也没有前端构建步骤。页面里的“运行回测”会调用
后端重新计算，不是静态图。

## 数据源说明

按课程要求，系统实际使用两个数据源：

| 角色 | 数据源 | 说明 |
| --- | --- | --- |
| 主源 | **akshare** | 日线、指数、股票池；走东方财富接口，限流时自动切新浪备用通道（当前 300 只股票池中 294 只走新浪，6 只走东财；manifest 另留 4 只早期腾讯缓存，不在当前股票池内） |
| 校验源 | **baostock** | 独立比对收盘价，验证主源数据是否可信 |

仓库里的行情就是用 akshare 抓的，`data/raw/_manifest.json` 里逐只记录了 `source` 与 `channel`
（东财还是新浪通道）。baostock 用来做抽样交叉校验：本次抽查 8 只，6 只逐日收盘价完全一致，
另 2 只最大绝对偏差分别为 0.001 元和 0.01 元，属低价股/指数的取整差异。

```bash
python -m qlab check --sample 15      # 抽查 15 只，逐日比对两个源的收盘价
```

腾讯与新浪接口仍然保留（`--provider tencent|sina`），用于历史兼容和 akshare 不可用时的回退；
新浪同时提供股票池列表，akshare 的股票池接口被限流时抓取脚本会自动回退到它。

```bash
python scripts/download_data.py                       # 默认 akshare
python scripts/download_data.py --provider baostock   # 换 baostock（较慢，约 10 秒/只）
python scripts/check_sources.py                      # 测各源连通性
```

数据保存在 `data/raw/`，约 30MB，已加入 `.gitignore`，因此克隆仓库后需要先执行一次抓取。

## 复现性

全部参数集中在 `qlab/config.py`，部分可由命令行覆盖。流程中没有随机采样，同一份数据重复运行
结果一致；需要说明的是，pandas 与 numpy 更换大版本时数值会有小幅差异，`requirements.txt`
目前给出的是版本下限。

因子计算与回测都只使用当日及之前的数据，滚动窗口一律向后取，T 日收盘生成信号、T+1 开盘成交。
`tests/test_engine.py` 中用一个次日跳空 10 倍的构造行情验证了这一点：若误按收盘价成交，
净值会被明显放大。
