# QLab：A 股多因子选股与趋势择时

周三上午班 L 组（4 人）课程作业。

本组实现了一套面向 A 股日频数据的量化研究流程，包括行情抓取与清洗、因子计算、选股与择时、
回测撮合、绩效统计与结果展示。回测引擎为自行实现，未调用 backtrader、vnpy 一类的第三方框架。

如果只想确认流程能跑通，直接双击 `回测.bat` 即可；需要了解细节，可先看 [新手使用说明](新手使用说明.md)。

## 环境与运行

Python 3.10 及以上，开发与测试环境为 3.12。

```bash
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
pip install pytest                    # 仅在运行单元测试时需要

python scripts/download_data.py --size 300 --rounds 3
python scripts/run_backtest.py
python -m qlab web                    # 默认 http://127.0.0.1:8000
python -m qlab report                 # 生成 Word 技术报告
```

`download_data.py` 需要联网，300 只标的约需十几分钟。若只是想验证流程，可以先抓 30 只：

```bash
python scripts/download_data.py --size 30 --rounds 1
python scripts/run_backtest.py --top-n 10 --no-ablation
```

## 策略设计

候选因子共 12 个，定义在 `qlab/config.py` 的 `FACTOR_POOL` 中，覆盖动量、反转、波动率、
流动性、趋势与高阶矩六类。每个因子附有方向标记，+1 表示数值越大预期收益越高，-1 表示相反。

因子的取舍只使用样本内区间（2019-01-01 至 2022-12-31）的月末数据。先计算因子与未来 21 个
交易日收益的横截面秩相关（Rank IC），再汇总为 ICIR。按 |ICIR| 从大到小依次纳入，若与已选
因子的截面相关性达到 0.75 则跳过，同时要求 |ICIR| 不低于 0.15，最多保留 5 个。

实际只有 3 个因子通过筛选：skew_60、turn_20、bias_60，方向均为反向。三者的样本内 t 值分别是
-1.78、-1.62 和 -1.54，未达到通常的显著性水平，技术报告中对此作了说明。

合成得分时，方向取样本内 IC 的符号，权重按 |ICIR| 归一化。每个调仓日先做 2% 的双侧缩尾，
再做横截面 z-score，然后加权求和；若某只股票当期缺少某个因子，则按剩余有效因子的权重重新归一。
组合取综合得分前 30 只等权持有，单票权重上限 8%，月末最后一个交易日出信号，次一交易日开盘调仓。

择时环节只调整总仓位，不改变选股结果：沪深 300 收盘价位于 120 日均线上方时满仓，
下方时将仓位系数降至 30%。

交易成本按 A 股规则设定：佣金万分之二点五、单笔最低 5 元；印花税在卖出时收取，
2023-08-28 之前为千分之一，之后为万分之五；单边滑点 5bp；买入按 100 股整手向下取整。

## 回测设置与结果

回测区间为 2019-01-02 至数据末端，样本内截至 2022-12-31，样本外自 2023-01-01 起，两段分别统计。
基准选用沪深 300 价格指数，与个股采用的不复权价格口径一致。

课程要求的四项指标均已给出，包括累计收益率、年化收益率、最大回撤与夏普比率；此外还计算了
索提诺比率、卡玛比率、信息比率、年化超额、Beta、Alpha、胜率与换手率。年化统一按 252 个交易日处理。

| 指标 | 策略 | 沪深300 |
| --- | ---: | ---: |
| 累计收益率 | 41.5% | 33.2% |
| 年化收益率 | 4.7% | 3.8% |
| 最大回撤 | -15.6% | -45.6% |
| 夏普比率 | 0.31 | 0.22 |

全样本的年化超额约为 0.8 个百分点，样本内为 -2.3%，样本外为 3.9%。收益端的优势并不明显，
回撤则比基准小很多，这是保留择时的主要原因。不过 30% 的低仓位设定偏保守，消融实验中关闭择时后
年化收益升至 15.4%，最大回撤扩大到 -23.1%，两种取舍的数值在技术报告中都已列出。

净值曲线按 1.0 起算，图上标出了建仓与加减仓的位置，并画出了样本内外的分界线。

## 数据来源与复现

行情来自腾讯的日线接口，股票池取自新浪的行情列表接口，两者均为公开免费接口，无需注册。
接口对高频访问有限流，抓取脚本采用单线程并在请求之间留出间隔，同时支持多轮补抓。此外也编写了
akshare、baostock 与 yfinance 的适配器，安装对应依赖后可通过 `--provider` 切换，默认使用腾讯。

数据保存在 `data/raw/`，约 30MB，已加入 `.gitignore`，因此克隆仓库后需要先执行一次抓取。

全部参数集中在 `qlab/config.py`，部分可由命令行覆盖。流程中没有随机采样，同一份数据重复运行
结果一致；需要说明的是，pandas 与 numpy 更换大版本时数值会有小幅差异，`requirements.txt`
目前给出的是版本下限。

因子计算与回测都只使用当日及之前的数据，滚动窗口一律向后取，T 日收盘生成信号、T+1 开盘成交。
`tests/test_engine.py` 中用一个次日跳空 10 倍的构造行情验证了这一点：若误按收盘价成交，
净值会被明显放大。

## 已知问题

- 股票池按抓取当日的市值排序取前 300 只，并非历史成分股，存在幸存者偏差，超额收益会被高估，
  这是本组认为最需要说明的一点。
- 300 只标的中只有 150 只进入回测：93 只因历史行情不足（2017-09 之前无数据）被剔除，另有 57 只
  未通过数据质量检查。腾讯接口对个别标的存在数量级错误，例如 601088 与 000408，单日涨幅可达 60%，
  若不剔除会严重扭曲净值。
- 采用不复权价格，收益中不含分红，绝对收益约被低估 2 个百分点。基准同为价格指数，两者口径一致，
  因此超额收益的比较仍然成立。
- 回测为日频、按开盘价成交，未模拟涨跌停无法成交以及复牌跳空等情形。
- 未接入实盘，系统仅用于策略研究与课程演示。

## 关于 AI 工具的使用

工程骨架、数据适配器、回测引擎、因子库、指标与绘图模块在编写过程中使用了 AI 编程助手
（DeepSeek Harness）辅助，之后由本组成员逐段阅读、运行与修改。策略思路、因子方向的经济含义、
样本内外划分方式与成本假设由本组确定。课程允许使用此类工具，同时要求如实说明，故在此列出。

核心策略与回测逻辑均为自行实现，未调用第三方回测框架。
